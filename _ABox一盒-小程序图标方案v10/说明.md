# ABox 一盒 · 小程序图标方案 v10

## 这一批变了什么

前七版反复栽在同一处：**要么靠"画字"（A / 一 / 盒），要么靠"画物"（插画式饭盒）**。
v8 想纯抽象，结果 01 读成用户头像、02 读成骰子、04 读成鱼钩笑脸——抽象到没有食物线索，就成了通用 UI 图标。

v10 定的规矩只有一条：**每个记号必须留一个"不可错认的食物线索"**（格 / 热气 / 碗 / 提手 / 套盒），
再用最克制的一两个形去说它。这样既高级，又不歧义。

## 我推荐 01「一饭四菜」

- **它自己会讲业务**：左边一大格 = 一饭，右边四小格 = 四菜。不用一个字，卖点全在形里。
- **40px 立得住**：分隔线 30px，缩到 40px 仍有 ≈1.2px，格子读得出来。
- **最能独占**：一般的"盒子"谁都能用；"一饭四菜的格"只有你在用。
- 它还是唯一一个**把套餐结构直接画成记号**的，别人抄不走。

次选：想强调"热乎送到"就 **04 提盒**；想强调"拼/团"就 **06 拼**；想要徽章信物感就 **07 套盒**。

## 规格

画布 1024×1024 · 双色 `#F6F0E5` / `#6E5435` · 主体占位约 66% · 均收在内切圆 r=340 内 · 奶白底款带一层 20% 棕投影（不出第三色）。
微信要求 ≥144×144、PNG/JPG、≤2MB，出 1024 为各处缩放不糊。

## 怎么改

`build.cjs` 里每款的 `body` 就是几行 SVG，改数字重跑即可（脚本会重出 1024 母版 + 总览）。
