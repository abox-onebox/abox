## 三、必须遵守的规则（铁律）

1. **品牌英文名大小写固定为 `ABox`**（A、B 大写，o、x 小写）。严禁 `ABOX` / `abox`。
2. **网格结构**：2×2 四格等大方块，读作 ABox。
   - `A / B / o`：米底 + 棕框（5px）+ **不填充** + **实心棕字**
   - `x`：**棕色填充框** + **奶色实挖**（＝盲盒，唯一有色块）
3. **反白（深底）**：用深底**实心奶字**，不要用奶色描边（描边会偏细、o 变双圈）。
4. **任何棕底 / 深色容器必须用反白版**，否则 x 的棕填格与底同色，X 会变成浮字。
5. **最小尺寸**：网格宽 ≥ 56px；圆形头像用「圆形安全区」版。
6. 中文名「一盒」用**楷体**，仅作注脚，不进入字母网格、不加框。

## 五、如何重新生成

```bash
# 需要：Node 22 + playwright-core + 本机 Chrome
export NODE_PATH="C:/Users/herma/.workbuddy/binaries/node/workspace/node_modules"

node build_full.cjs   # 生成 00 + 01–26 全部 PNG
node build_pdf.cjs    # 生成 ABox_品牌物料手册.pdf
```

改尺寸/配色只需改 `build_full.cjs` 顶部的 `CREAM` / `BROWN` 常量与各 `gridHtml(k, mode)` 的 `k`（缩放系数）。修改后请保持「A/B/o 带框不填充实心、x 棕填实挖」的铁律。
