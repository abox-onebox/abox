五、打不开 / 扫不开 怎么排

按顺序排除，别急着记缺陷
  • 手机提示「无法打开网页」：九成是 Windows 防火墙拦了 node.exe —— 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 勾上 node.exe（专用网络）。
  • 电脑上能开、手机不能：多半是手机没连同一个 WiFi，或连的是 5G 访客网络（与电脑不同网段）。
  • 昨天能开、今天不能：本机 IP 变了。重新跑一次生成脚本，卡上的地址与二维码会一起刷新。
  • 后台登录提示「请求过于频繁」：同账号 1 分钟内失败登录 5 次触发限流（与生产一致）。等 1 分钟自动恢复 —— 属预期行为。
  • 页面全白 / 转圈：先开「接口健康检查」。它通 → 问题在页面或数据；它也不通 → 环境没起来，重跑第四节的命令。
  • 支付走 Mock 通道：会自动回调成功，但不产生真实资金流。
