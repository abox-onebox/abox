问题：x 是在首页被制造出来的悬念，但"揭晓一道轻食"份量太轻，不值得为它开一个完整供应商页（原概念 06 的症结）。

原则：让悬念在它出生的同一块屏幕闭环，或用已有页面 / 微信通知承接，绝不新开导航页。下面五屏是用户实际会看到的完整界面。

  • 推荐① 首页 x 格自揭晓（同屏闭环，零跳转） 送达后，x 格「?」自动翻成今日实物（如"小粗粮"）并打"今日x揭晓"标。谜题在它被造出来的地方解开，最自然。
  • 推荐② 点 x → 底部弹层（sheet，非 page） 沿用首页已有弹层样式，承载"今日揭晓 + 本周回顾 + 集盒进度"。浮层非导航页，关掉即回首页。
  • 零页面③ 送达订阅消息揭晓（纯通知） 团长送达时推一条微信订阅消息。惊喜活在通知里，App 内零新增界面。
  • 复用④ 订单详情内联（复用已有"订单"页） 现有订单详情里，x 那一行送达后显示"你抽到了：小粗粮"。只是把已有字段填实。
  • 复用⑤ 我的页·集盒小卡（已有 tab 上的轻 widget） 在"我的"里放一张小卡：本周 x 收集进度，集齐得勋章。轻量游戏化，不占导航。

建议组合：① 首页自揭晓（主惊喜） + ② 点 x 弹层（看本周回顾） + ③ 送达订阅消息（触达）。下方五屏逐一可看。
