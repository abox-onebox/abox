# 图标清单 v2.1

- 库：Tabler Icons（MIT）· 24×24 · 描边 1.5/1.6/1.7 · **两端共用一套**
- 尺寸锁三档：16px（行内）/ 20px（按钮内）/ 24px（独立）
- 本表共 82 个语义名，覆盖：导航分组 · 动作 · 状态 · 业务（菜品品类 / 平台 / 场所）

## 落地形态（关键）

小程序**不支持** `<use href>` 引用外部 svg，内联 `<svg>` 与 `<image>` 在小程序内表现不可靠。
故两端共用一套的**唯一可执行形态**为：冻结成 **iconfont 子集（base64 内嵌 woff2）** 或
**data-uri 背景图**，字形文件同一份，两端引用同一个类名。
