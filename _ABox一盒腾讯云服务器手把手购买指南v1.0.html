一 · 买之前：先定四件事

这四件定不下来，进去点"立即选购"只会反复改配置。

决策一：用哪个账号买

方案好处代价 / 风险
公司主体账号
（企业实名）		一次到位。以后备案、支付商户号、小程序主体全在同一主体下，不用迁移受公司经营异常牵制 —— 企业认证可能被卡。这个必须你先找代理确认
个人 / 现有账号
建议先用		当天就能买、当天就能测，不被资质卡住以后要用公司形象正式上线时，需换账号重买一台，重跑一次部署（约 30 分钟，成本不高）
我的建议 分两次走

现在的目标只是"让同事测起来"。用能立刻通过实名的账号买一台先跑起来，把部署流程、公网友好性、同事体验都验证一遍； 等公司经营异常解除、备案主体确定后，再买正式那台。

理由：部署成本已经被这次演练压到很低（《线上联调部署清单》十步，重跑一次约 30 分钟）， 用一次部署的时间换"不被资质卡死"，很划算。

决策二：买哪种

选
轻量应用服务器 Lighthouse，不要选云服务器 CVM
理由
价格便宜、自带带宽与流量包、控制台简单。我们要的只是在上面跑 Docker，CVM 那些弹性网卡、安全组、快照策略一个都用不上

决策三：什么配置

机型
4 核 8G（配套 SSD 与月流量由套餐自带，不用单独选）
地域
境内，选离北京近的地域（北京 / 上海）。境外节点确实免备案，但延迟明显且以后上线还得迁回来
镜像
系统镜像 → Ubuntu 22.04 LTS。别选应用镜像（宝塔/WDCP 那类），它们预装的面板会占端口、改 nginx 配置，跟我们的部署脚本打架
数量
1 台。本项目一期有单实例约束（订单时间是进程级单例），买多台做负载均衡反而会出错

决策四：买多久 —— 这里有个新发现

好消息 腾讯云产品页在推「新用户免费体验 1 个月（个企同享）」

见下方实测截图。如果你符合新用户条件，内部联调这一个月的机器钱可以先不花。

路线适合注意
免费体验 1 个月本次内部联调（不备案、不收款，只验证流程）名额与机型以购买页实时显示为准；到期后需另购正式实例
包年包月 ≥ 3 个月以后要走备案 / 上线备案资格要求包年包月且购买时长 ≥3 个月，按量与试用不支持

两者不冲突：先免费用起来，验证完再决定正式机的买法。

二 · 预算：花多少

心里有个数，看到价格页不会被吓到，也不会被"便宜 30 元"诱导选错。

档次参考价格适用
4 核 8G 高配新人活动价约 600–700 元/年，日常价约 1,500–2,500 元/年我们要买的
4 核 4G 中配新人秒杀价低至几十元/年（限量抢购）看着便宜，但跑不动（见下）
2 核 2G 入门约 68–99 元/年明确不够，不要买
硬禁忌 不要为了便宜选 2C4G / 4C4G

这台机器上要同时跑 MySQL + Redis + API + nginx，而且要在机器上构建两个 Node 镜像——构建峰值最吃内存。

4C4G 的典型症状是构建到一半进程被系统杀掉，报一个孤零零的 Killed，没有任何其它报错， 极易误判为代码问题，排查方向完全跑偏。

以上价格为 2026-10 检索到的公开促销信息量级，实际以你打开购买页那一刻显示为准——腾讯云的价格和活动几乎每月变。

三 · 一步步操作（附真实截图）

下面三张图是 2026-10-01 用真实浏览器抓取的腾讯云页面，红圈标注了点击位置。

表单里的每一步

1注册 / 登录腾讯云账号 你做

打开 cloud.tencent.com → 右上角「免费注册」→ 按提示完成注册与实名认证。

注意 实名认证是绕不过的一步

不实名买不了境内服务器。个人实名通常快（人脸识别几分钟）；企业实名要走工商信息核验，可能 1–2 个工作日。

2进入轻量应用服务器购买页 你做

两条路都行：

① 产品页 cloud.tencent.com/product/lighthouse → 点「立即选购」；
② 登录后直接进控制台 → 左上角「云产品」→ 搜「轻量应用服务器」→ 右上角「新建」。

3选地域 你做

「地域」选中国大陆 → 北京（离昌平最近，延迟最低）。

硬禁忌 别选境外（中国香港 / 新加坡 / 硅谷）

境外确实免备案，看起来很诱人。但三笔账要算清：延迟明显、以后正式上线时还要迁回境内重新部署、 以及届时小程序的用户体验与合规口径都要重来。除非你明确只要临时跳板。

4选套餐与镜像 你做
套餐
在套餐列表里挑 4 核 8G 那档（CPU / 内存 / SSD / 带宽 / 月流量都是套餐自带的，通常不用单独调）
镜像
切到「系统镜像」页签 → Ubuntu Server 22.04 LTS 64位
数量
1 台
注意 Ubuntu 版本号不用纠结

22.04 与 24.04 都能跑我们的脚本。写 22.04 只是因为它是最稳、资料最多的 LTS； 如果购买页当前主推 24.04，选它也没问题。

5选购买时长 你做
本次联调
先走免费体验；没有资格就选最短的付费周期（通常 1 个月可选）
若要备案
必须包年包月且 ≥ 3 个月
硬禁忌 务必看一眼「自动续费」是否被默认勾选

很多套餐默认勾选自动续费。到期自动扣款不难取消，但容易忘。不需要就当场取消。

6确认订单并支付 你做

右侧「费用合计」核对一遍金额与时长 → 同意协议 → 支付。

支付完成后 1–2 分钟机器就会出现在控制台，状态变为「运行中」。

7立刻设置登录密码 / 密钥 你做

创建过程中或创建后，在实例详情里重置 root 密码（有的地域要求创建时就设）。设一个强密码并存好——后面 SSH 全靠它。

顺手把这台机的公网 IP 记下来：《线上联调部署清单》里全程用它。

五 · 六个容易吃亏的地方

1 · 贪便宜买低配

2C2G / 2C4G 在构建阶段会被 OOM Killer 杀掉，报 Killed 且无其它报错。省下的几十元会用几小时的排查还回去。

2 · 选了"应用镜像"（宝塔面板等）

预装面板会占用 80/443/8888 端口并自行写入 nginx 配置，与我们的 Docker 编排冲突， 症状是"容器起来了但端口打不开"，且很难想到是面板在作怪。

3 · 买了境外节点图省事

免备案的代价是：延迟高、未来必须迁回境内重来一遍。除非你只要个临时跳板。

4 · 忘记取消自动续费

下单那一刻顺手看一眼，比事后想起来省事。

5 · 新用户优惠只认一个主体

优惠是按实名主体算的。你现在用哪个账号买了，这个主体的"新用户"就消耗掉了—— 所以决策一（用哪个账号买）要在点支付之前想清楚。

6 · 买完才发现忘了记公网 IP 或密码

两样东西都能在控制台找回或重置，但会浪费时间。创建时就随手存好。

六 · 买完之后立刻做的三件事

机器到手不等于能开测，这三件事决定了后面的步骤顺不顺。

1防火墙只开 22 和 8080 你做 · 控制台

轻量服务器 → 防火墙 → 添加规则。3306（MySQL）和 6379（Redis）绝不开——开了等于把数据库裸露在公网。

2验证 SSH 能连上 你或我
ssh root@<你的公网IP>

能出现命令行提示符即通过。连不上先回控制台确认密码是否正确、22 端口是否放行。

3把公网 IP 发给我（或照清单继续） 你或我

之后 A3 到 A8 的步骤（装 Docker、拉代码、跑 deploy.sh、三条验收判据）我可以直接登上去替你跑完—— 本机 OpenSSH 可用，你只要把 IP 和 root 密码给我、并把 22 端口放行即可。

也可以你自己照《_ABox一盒线上联调部署清单v1.0.html》逐步敲，效果一样。
