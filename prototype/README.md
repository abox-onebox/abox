## v4.7.8 身份概念改造（2026-09-14 16:30）

### 业务问题
用户测试发现原型顶部 4 个角色 tab 切换"用户端 / 团长端"像两个小程序，但实际业务中**用户与团长共用同一小程序身份**，团长只是叠加身份。

### 关键改造

| 项 | v4.7.7 | v4.7.8 |
|---|---|---|
| 顶部 tab | 4 个（含团长端） | **3 个**（用户端 / 商家端 / 后台） |
| P11-P20 role | leader | **user**（同身份） |
| 团长入口 | 顶部切 tabBar | tabBar 中间多一个📦团长图标（动态出现） |
| 身份持久化 | 无 | **localStorage** 跨刷新保留 |

### isLeader 动态身份系统
```js
let isLeader = localStorage.getItem('abox_is_leader') === '1';
function setIsLeader(v) { isLeader = !!v; localStorage.setItem('abox_is_leader', isLeader ? '1' : '0'); renderAll(); }
```

### tabBar 动态化
| 用户类型 | tabBar |
|---|---|
| 普通用户 | 首页 / 供应商 / 订单 / 我的（4 项） |
| 团长用户 | 首页 / 供应商 / **📦团长** / 订单 / 我的（5 项） |

### 团长用户专属入口
- **P1 首页**：套餐包装卡片下方插入"📦 您是见习团长 · 本月已促成 8 单 → 进入工作台 ›"金色横幅，点击直达 P11

- **P20 团长资料**：底部"退出团长身份" → 二次确认 → switchTab 到 P8

## v4.4 业务逻辑审查修复（9 处）

### 🔴致命：#1 P37 配送时间窗口冲突
**问题**：P37 集散中心映射按"12 站串行"设计（每站 15-25 分钟），总时长 234 分钟 ≈ 4 小时——**远超货拉拉 10:00-11:30 的 90 分钟配送窗口**，业务跑不通。

## 一、新版本（v3.0）的核心变化

## v4.7.1 热修（2026-09-13 16:30）

**症状**：用户端点击 tabBar「供应商」跳转到了 P11 团长工作台，而非 P38 供应商页。

**根因**：`switchPage(index)` 中同角色跳转用了 `sameRolePages[0].i + 同角色位置` 计算 visibleIndex，该公式只在同角色页面于 PAGES 数组中**连续**排列时正确。v4.7 把 P38 跳号插入到数组末尾（index=36，与用户端连续段 P1-P10 间隔了团长端/商家端/后台 18 页），于是 P38 在 sameRolePages 中的位置 9 被错误地映射到 PAGES[9] = P11。

**修复**：去掉累加计算，同角色页直接 `visibleIndex = index`（PAGES 数组 index 本就合法），跨角色才 fallback 到该角色首页。

**影响**：所有 tab 跳转 / 顶部角色 tab 切换 / 下拉索引跳转全部恢复正常。

## v4.7.7 导航栈重构 + PWA（2026-09-14 15:10）

### 一、导航栈重构（核心修复）

**症状**：页面跳转链混乱——点 A→B→C 后按返回，落点不确定（有时跳首页，有时跳不相关页），无法连续研究业务流程。

**根因**：原型原先没有"导航栈"概念，37 个页面平铺，每页返回按钮各自写死目标（`goToPage('P3')`）或调 `goPrev()`（= PAGES 数组前一个 index，跨角色时会乱跳）。

**新机制**：

| API | 作用 |
| --- | --- |
| `switchPage(index)` | 底层切换，自动入栈（`_suppressPush` / `_navBackInProgress` 可抑制） |
| `switchPageNoPush(index)` | 不入栈切换（tabBar / 角色切换 / 栈空兜底用） |
| `navigateBack()` | 弹栈返回，恢复滚动位置；跨角色时同步 currentRole；栈空则回角色首页 |
| `switchTab(pageId)` | tabBar 切换：**清栈** + 同步角色 |
| `switchRoleFn(role)` | 顶部角色 tab：**先更新 currentRole** 再清栈跳角色首页 |
| `goToPage(id)` | 页面内跳转：**智能回退**——目标页若已在栈中，截断栈到该位置 |
| `goPrev()` | 保留为 `navigateBack()` 别名（兼容旧调用） |

**修复的 3 个 bug**：

1. `switchTab` / `switchRoleFn` 清栈后立刻被 `switchPage` 自动入栈 → 加 `_suppressPush` 标志
2. `switchRoleFn` 未先更新 `currentRole` → `switchPage` 的角色过滤把目标页打回原角色首页（切团长端却停在 P1）
3. 栈上限 `if` 只 shift 一次 → 改 `while` 保证不超限

**新增交互**：
- 浏览器**后退键 / 手势返回** → 监听 `popstate` 走导航栈
- 键盘 `←` = 返回上一页（原为页序前一个），`→` = 页序下一个
- 顶部 `‹` 按钮与各页 navBar 返回按钮统一走 `navigateBack()`
- 返回时**恢复来源页的滚动位置**
