供应商页创新 · 眼前一亮版

上一版 29 条是「功能补全」视角——把供应商当「信息货架」，补菜单 / 补证照 / 补数据，所以你觉得平、没惊喜。 本版换「体验创新」视角——把供应商当成 直播间 / 一个活人 / 一场比赛 / 一个你能养成的对象， 靠实时、情绪、互动、惊喜制造「眼前一亮」，而不是靠堆信息。
范围：纯原型讨论，不落码。合规底线不变（小程序内不得出现第三方平台名 / 不做二清 / 不做抽奖赌博 / 营养不做声称）。 下方 9 个新概念 + 3 张可看原型。
一、九个「眼前一亮」新方向（非功能补全，是体验创新）
标记：最亮 我私推优先做；合规安全 可行中 合规注意
01
后厨实时直播 · 明厨亮灶
点开供应商页，正看到你这盒饭在哪个灶台炒、蒸汽升腾——不是录播，是此刻。
从「看证照」到「看此刻」，信任从纸面跳到眼前，监管也鼓励明厨亮灶。

02
主厨 IP · 每日朋友圈
每个厨房有个主厨角色：「凌晨 5 点的菜场，挑了最嫩的菠菜」配一张图，像追更一个活人。
把冷冰冰的「供应商」变成有温度的「人」，连续剧式情感连接，图文即可落地。
最亮合规安全可行高
03
厨房养成 · 你这栋楼在养它
你们楼的订单让这家厨房升级：路边摊 → 社区名厨 → 金牌中央厨房，解锁成就徽章。
用户从「消费者」变「养成者」，归属感与复购动机强；纯展示订单量，无赌博。
最亮合规安全可行高
04
本周厨神争霸 · 实时打榜
各供应商本周被订次数实时排名：「你这一单，把三味屋顶到了第 1」。
竞技 + 社交货币，用户有「我参与了」的爽感；仅展示订单量排序，不做抽奖。
合规安全可行高
05
从农田到工位 · 一日纪实
滑动看这盒饭的旅程：6:00 农贸市场 → 8:30 切配 → 10:00 烹饪 → 11:30 到你工位。
叙事化透明，把供应链讲成有头有尾的故事，比冷冰冰的「来源」更打动人。
合规安全可行中
06
X 盲盒厨房 · 招牌神秘菜（联动首页）
和首页x 盲盒呼应：每家供应商有自己的「神秘招牌」，今天可能是秘制卤味。
注意：单为「揭晓一道菜」开一整页太重，已降级——x 的悬念与揭晓改走首页轻量处理（自揭晓 / 底部弹层 / 送达订阅消息，见《x 盲盒轻量揭晓方案》）。本概念保留为「神秘招牌历史沉淀」入口，但不单独为揭晓占页。

共创菜单 · 你来点菜我做
你提交想吃的菜，每周票选 Top，供应商真的做出来并 @ 提议者。
UGC 反向供给，用户从被动吃变主动点，被看见的成就感极强。
合规安全可行中
08
解压治愈 · 后厨白噪音
短循环视频：切菜声、油锅声、蒸汽声——午休点开解压三分钟。
给页面加「情绪价值」，让用户愿意多停留；零合规风险，素材好采。
合规安全可行高
09
口味基因检测 · 趣味匹配
答几题测出你是重口派 / 养生派 / 尝鲜派，匹配最适合你的供应商，结果可分享。
社交传播 + 个性化推荐；注意不做任何医学 / 营养声称，纯娱乐标签。
