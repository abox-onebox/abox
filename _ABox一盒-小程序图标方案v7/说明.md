# ABox 一盒 · 小程序图标 v7 · 真楷体字标 + 印章

## 这一版换了根方法

前六版我一直在用**几何块拼字**——直边、等宽、无笔锋。那正是"显 low"的根源：它看起来像素材站的免费图标，而不像一个人写的字。

这一版改用**真楷体渲染**（SimKai，就是你品牌在用的楷体）。笔锋、捺脚、提按轻重全是字体本身带来的，手搓几何永远做不到。

同时按你的话，**A 退场**。主角换成项目真正的两个字根：

- **一** —— 周一、一盒、一饭四菜、一笔落墨
- **盒** —— 本体、合团、天地盖容器

A 只是品牌代号，不承载业务；「一 / 盒」才是这个项目每天都在说的事。

## 我的推荐

1. **小程序头像 → 01 白文印·盒**。最厚重，40px 下轮廓最清楚；"盒"字笔锋在小尺寸也立得住。
2. **包装 / 名片 / 封条 → 01 + 02 配对**。同一套语言的阴阳两版，白文盖封条、朱文印腰封。
3. **要信息最全 → 06 白文竖排·一盒**。一款里同时有"一"和"盒"，盖在哪儿都是一句完整项目名。
4. **社媒 / 贴纸 → 03 圆印·盒**。

## 三个诚实的短板

- **08「白文印·一」在 40px 下只剩一条白线**。作为盖在包装、名片上的印章是成立的，但**不适合当小程序头像**——这是我自己的判断，先标出来，不推荐它做图标。
- **04 / 05 的"一"与"盒"间距偏宽**。楷体"一"字本身占位宽，视觉上两字分得开；要更紧可把 letter-spacing 调负。
- **印章的"做旧"没做**。现在四边是干净的直边；若要更真实的印泥感（边缘残缺、墨色不匀），需要额外一层纹理，可以下一版加。
