第一部分 · 查你的域名有没有备案过

先分清三个不同的问题，别混着查——很多人在这里绕弯。

1.0先分清：你要查的到底是哪件事
问题在哪查查到什么算数
域名在哪家注册的？WHOIS 查询（见 1.3）注册商名称 + 到期日期
备没备案过？工信部官方查询（见 1.1，权威）有备案号 = 备过
备案的「接入商」是谁？同上（看备案详情里的接入商字段）接入商名称——它决定你要不要办接入备案
为什么「接入商」最关键

备案绑定实际接入服务商。若你的域名备案接入商不是腾讯云，换到腾讯云部署时必须办接入备案（管局终审 1–20 个工作日）；若原备案已失效会被注销、要重新备案。所以查备案时别只看"有没有备案号"，要看接入商那一栏。

1.1路线 A · 工信部官方查询（权威 · 免登录）我无法代测

官方网站：https://beian.miit.gov.cn/（工信部 ICP 备案管理系统 · 公共查询，不需要注册登录）。

操作步骤

  1. 浏览器打开 beian.miit.gov.cn，首页顶部菜单点「信息查询」（或「公共查询」）。
  2. 选「备案信息查询」。
  3. 查询方式选「域名查询」，输入你的域名——不带 www、不带 http（例如 example.com.cn 就填 example.com.cn）。
  4. 拖动滑块完成人机验证 → 点「查询」。
  5. 结果里点开详情，重点看两个栏目：备案号（有没有）和接入商（是谁）。
诚实说明：这一站我从这台机器打不开

2026-09-29 我用真实浏览器实测 beian.miit.gov.cn，HTTP 与 HTTPS 均返回 521、页面 0 字（换 UA、换协议同样）。常见原因是该站对境外/非常规出口限制访问——你在国内网络下大概率能正常打开。所以这一步请你自己操作，上面 5 步是官方流程。

若你也打不开，用路线 B（登录腾讯云后查，数据同源——腾讯云备案数据直接对接管局系统）。

结果判读

查到的结果意味着什么你接下来要做的
无备案记录从未备案走第二部分「新备案」流程
有备案 + 接入商 = 腾讯云直接可用什么都不用办（确认备案在有效期内即可）
有备案 + 接入商 = 其他服务商需「接入备案」走第二部分「接入备案」，1–20 个工作日
有备案但主体/域名信息异常可能已失效先问原接入商确认状态，失效会被注销
1.2路线 B · 腾讯云备案控制台查（需登录）需你扫码
  1. 打开 console.cloud.tencent.com/beian → 用微信/QQ 扫码登录（这一步只能你来）。
  2. 在备案控制台内找「备案信息查询 / 我的备案」类入口（控制台内部菜单随版本调整，以你登录后看到的为准——我无法登录核实，不猜菜单名）。
  3. 若你的域名从未在腾讯云备过，这里可能查不到记录——这不代表没备案过，还是要回到路线 A 查全量。
我能验证到的边界

未登录访问该地址会跳转到登录页（实测确认）。登录后的界面我看不到，所以这一路线只给到「入口」级，不编造内部菜单名。

1.3路线 C · WHOIS 查域名注册商（顺带把域名买到手）真实截图

如果你还没有域名，先在这里买。腾讯云域名页（cloud.tencent.com/product/domain）顶部就有查询框，直接输入想注册的域名：

输入一个域名（示例 aboxcanyin2026.com），点右侧蓝色「查询域名」按钮：

查到之后怎么判断

显示「立即购买」= 未被注册，可直接买；显示价格/被注册 = 已被别人注册，换一个或走域名交易。买域名必须用企业实名（与备案主体一致），否则备案时对不上。

已注册的域名怎么查注册商

域名页「建站工具」栏里有「WHOIS 查询」入口（上面第一张截图可见），输入域名可查注册商与到期日。但注意：WHOIS 查的是注册商（域名在哪家买的），不是备案接入商——两码事，别混。

勾选本节执行清单（做完一项勾一项）
已在 WHOIS/注册商后台确认域名在哪家注册、何时到期
已在工信部（路线 A）查询备案记录
已记下备案「接入商」是谁（这是决定下一步的唯一关键）
结论已明确：未备案 / 接入商=腾讯云 / 需接入备案（三选一）

第二部分 · 没备案（或接入商不对）→ 怎么备案

以下流程与时限全部取自腾讯云官方备案页当日实拍，逐字核对过。

2.1备案前，把这 4 样备齐你准备
材料要求你们的情况
营业执照彩色扫描件，信息清晰北京巡礼之年科技有限公司
法定代表人身份证正反面彩色照片你本人
备案服务号 / 云资源需先有符合条件的腾讯云服务器（包年包月 ≥3 个月）所以先买服务器再备案（第三部分）
网站负责人核验手机端人脸核验（流程第 2 步）你本人扫码做人脸识别
先处理公司经营异常，再提交备案

公司目前「存续但经营异常未移出」（2026-07 列入）。管局审核会核验主体资质，经营异常状态可能导致备案被退回——被退回一次就要重走一轮，白等几周。建议：提交前先向代理确认异常解除进度；若一时解除不了，也可以先提交试试（退回重来的成本是时间），但要有心理预期。

2.2官方六步流程（含每步时限）真实截图

入口：腾讯云备案产品页 cloud.tencent.com/product/ba，点蓝色「开始备案」按钮：

官方流程与时限（下图逐字抄录）：

步环节你要做什么 / 注意什么
1填写备案信息主体信息（营业执照）+ 网站信息（域名、网站名称、服务内容）。网站名称别带「一盒/盒饭」等纯经营词，用与公司名/品牌相关的中性名更容易过初审
2人脸核验手机小程序端，网站负责人（你）人脸识别，几分钟完成
3腾讯云初审1~2 个工作日。有问题腾讯云会电话/站内信联系修改
4短信核验工信部发短信到负责人手机，收到后 24 小时内必须完成核验——漏了直接作废退回。这就是之前提醒过的 12381 短信
5管局审核20 个工作日内（北京管局通常 1~2 周）。期间保持电话畅通，管局可能来电核实
6备案成功拿到备案号（如 京ICP备xxxxxx号），须在网站底部公示
审核期间有一条容易忽略的要求

接入备案（换接入商那种）审核期间，网站需保持可访问供核验——所以旧接入商那边别先停掉服务。全新备案（域名从未备过）没有这条，因为本来就没有站。

2.3更细的官方文档（材料清单、小程序端操作）真实截图

三个提醒：

  • 备案成功不是终点：文档目录里的「公安联网备案」——拿到 ICP 备案号后 30 天内还要去全国互联网安全管理服务平台（beian.mps.gov.cn）做公安备案，别漏。
  • 小程序也需要备案：2023 年起 APP/小程序备案是独立动作，在微信公众平台的备案流程里做（这与域名 ICP 备案并行，不是同一件事）。
  • 经营性备案（ICP 许可证）：你们的盒饭预订属电商类，初期一般用不到 ICP 经营许可证；若日后做平台型业务再评估。

第四部分 · 服务器到手后 → 部署

部署是纯命令行操作，图文版在这里：《_ABox一盒后台从零部署腾讯云操作手册v1.0.html》（工作区根目录，11 步 · 28 个可复制命令块）。这里只放主线：

开防火墙(22/80/443，不开8080) → 装 Docker → 固定时区 Asia/Shanghai → git clone 代码 → 写 .env.prod（PROVIDER_MODE=real 等3项必改） → ./scripts/deploy.sh --dry-run → ./scripts/deploy.sh → 验收：容器全 Up + migration:show 两支[X] + /health/ready 200 → 宿主机 nginx + certbot 上 HTTPS
部署时最容易出事的三条（详见命令手册）

① PROVIDER_MODE 必须显式写 real——留 mock 等于任何人可免密登录任意身份、支付自动置为已支付，且零报错；② 8080 绝不开公网，只给宿主机 nginx 反代；③ 验收只认「migration:show 两支都是 [X]」，部署脚本显示"迁移已执行"不算数。
