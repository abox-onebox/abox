# ABox 一盒 · 小程序图标方案 v5

> 这一批的唯一原则：**每个标记都必须看得见项目名本身**——A / Box / 一 / 盒。不再有蒸汽、圆环、箭头、小人这些与名字无关的符号。

## 十款

| # | 名称 | 字根 | 怎么挂钩 |
|---|---|---|---|
| 01 | **A·盒** ⭐ | A + Box | 字母 A 嵌进方框 = 字面 A Box |
| 02 | **双框A印** | A + 印 | 双框方印，A 撑满印心 = 信物 |
| 03 | **负A盒** | Box → A | 米色方盒里透出棕色 A（负空间） |
| 04 | **合** | 盒之音 | 人顶 + 一 + 口 = 「合」，盒的读音根 |
| 05 | **盒即A** | A + Box | A 悬在盒上，名字拆成上下两截 |
| 06 | **一盖盒** | 一 + 盒 | 一道「一」作盒盖悬在盒上，竖读「一盒」 |
| 07 | **AB** | A + B(ox) | 左 A 右 B，B 的两个圈是两只方盒 |
| 08 | **一笔A盒** | A + 盒横 | 书法 A，横杠本身就是一只小盒 |
| 09 | **盒** | 本字 | 直接用「盒」字（合 + 皿） |
| 10 | **套盒A** | Box→Box→A | 盒套盒，最中心是 A |

## 推荐

- **做小程序头像 → 01「A·盒」**：名字最直白，40px 下最清楚，别人在列表里一眼念得出 A Box。
- **做包装 / 名片 / 社媒的信物章 → 02「双框A印」**：同一套语言里最有"印章/收藏"质感的一款。
- **面向中文重度用户 → 09「盒」**：直接把品牌字做成记号，辨识度最高（但细节较多，超小尺寸要让位给 01）。

## 规格

- 画布 1024×1024，纯双色 `#F6F0E5` / `#6E5435`，暖棕满铺 + 极淡米色内框（成品 tile 感）。
- 所有图形收在内切圆安全区，微信圆角 / 圆形遮罩都不缺角。
- 微信只要求 ≥144×144、PNG/JPG、≤2MB；出 1024 是为各处缩放不糊。
