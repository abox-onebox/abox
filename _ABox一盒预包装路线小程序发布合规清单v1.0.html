小程序发布合规清单 · 预包装快消路线

ABox 一盒 · v1.0 · 2026-10-21 · 不含食品经营许可证
一句话结论

换成预包装快消品后，最重的那道门（实体加工场所 + 《食品经营许可证》+ 现场核查）整条消失了。 剩下的都是主体资质类手续：微信认证、服务类目、两套备案、域名 HTTPS、支付商户号。总周期约 3 周，且大部分可并行。

一、路线变了，哪些东西直接从清单里消失

之前为盒饭准备的现在还要吗
《食品经营许可证》（热食类制售）不需要改走备案
自有持证加工场所 / 实体门店不需要备案无现场核查
「证照地址 = 出餐地址 = 网店地址」三一致不适用
123 号令全套（食安封签、配送培训、无堂食标识）不适用那是网络餐饮口的
《增值电信业务经营许可证》EDI / ICP 证不需要自营卖自己的货，非第三方平台
已完成的「预包装食品备案」正是它这条路的核心凭证

二、要办的清单（7 项）

事项性质要点与耗时
1. 营业执照经营范围先确认 必须含「食品经营（仅销售预包装食品）」字样。北京口径：经营范围有这句话 = 视为已备案，不用再单独办证、不单独发证。没有的话先做经营范围变更（e 窗通，1–3 工作日）
2. 网络经营报告别漏 备案信息里若没勾「网络经营」，小程序开卖起 10 个工作日内须向属地市场监管部门补充报告
3. 微信认证
注意：非企业微信认证		硬前置 企业主体 300 元/年，1–3 工作日。不通过一般不退费，材料一次备齐。没认证 = 不能备案、不能开支付
此认证在 mp.weixin.qq.com（小程序后台）做，与 work.weixin.qq.com 企业微信是两套独立账号、独立费用，互不相干。操作路径：左侧「设置」→「微信认证」→「开通」→ 填企业资料 + 上传营业执照 + 对公打款或微信支付 300 元 → 等待腾讯审核（1–3 工作日）。
4. 微信服务类目硬前置 选「电商平台 / 商家自营 - 食品」类目，上传营业执照（含上述经营范围）。不再是「餐饮服务」。3–7 工作日
5. 小程序备案硬前置 平台初审 1–2 工作日（有电话核验）→ 12381 短信核验 24 小时内（超时整套作废）→ 北京通管局 1–2 周。详细填写步骤见《_ABox一盒小程序备案详细步骤v1.0.html》
6. 域名 ICP 备案并行 你已购 xunlizhinian.cn，10-18 起可提交。腾讯云初审 1–2 → 12381 短信核验 24h → 北京管局 7–14 工作日。这是全程最长的一段，先启动
7. 支付商户号 + HTTPS可稍后 微信支付普通商户号（营业执照 + 对公账户）；备案通过后配 api.xunlizhinian.cn + SSL 证书

三、顺序：最容易排错的一处

很多人先去做「小程序备案」，结果卡住——因为备案的前置是「已有 ≥1 个通过的服务类目」，而类目又要先看资质。

营业执照含经营范围（=已备案）
　→ 微信认证 → 服务类目通过 → 小程序备案 → 提审 → 发布
　　　　　　　　　　　　　　　　　└─ 域名备案（并行支线，最长，最早启动）

域名备案不和它串行，但不做完，小程序即使发布了也发不出请求——后端接口域名必须已 ICP 备案，且备案主体必须与小程序认证主体完全一致。

四、三条红线（这条路真正会出事的地方）

  1. 资质混用——备案只给你「卖别人造好的、带完整标签的预包装食品」的资格。一旦加热、拆包分装、调味复配、改保质期，就从「销售」滑进「制售」，要《食品经营许可证》，且届时备案自动失效。行业原话：「很多商家用预包装食品备案上架加工食品，最终被巡检处罚，核心就是资质混用。」
  2. 不能藏——微信要求类目与实际功能一致，不得隐藏或多次跳转；124 号令要求店铺主页显著位置持续公示资质（常驻功能，不是提审时贴一次），并与实际售卖的一致。
  3. 单品逐一确认——如果快消品里有酒类，需另行确认（部分地区预包装备案不含酒类）；进口商品须有中文标签与入境检验检疫证明。这两类先单独问清楚再上架。

五、你现在就可以动的两件事

  1. 域名 ICP 备案现在就能提了（xunlizhinian.cn，10-18 起已过静默期）。这是整条链里最长的一段，今天提就今天开始计时。
  2. 核对营业执照经营范围里有没有「食品经营（仅销售预包装食品）」这一句。有就不需要再办任何食品侧手续；没有就先做经营范围变更。
