一、六处改动，逐条说清为什么

#性质改了什么为什么
⑥ 补疏漏 「来自：X」补回 › 上一版为配合 B 稿弹层把它去掉了，但中栏不带弹层 ⇒ 等于砍掉了现有能力。 补回后点击行为维持现状（openSupplier(d) 跳溯源页），不改后端。
① 视觉 天盖下缘加盖沿 天地盖的识别特征是「盖子压住盒身」那道边。做法：上圆角下直角 + 下缘一条内阴影（inset 0 -7px 11px -7px）。零新增元素，纯 CSS。
② 视觉 天盖与地盒之间加盖缝 3px 横条，两端淡中间深（--gold-deepest 渐变）。 没有它，盖和盒就是上下两块色，看不出是两个部件。
③ 视觉 盒身沉一档，白格浮起 本轮最关键的一处。盒身 --surface2、格子 --surface 白底 + 轻投影 ⇒ 格子间的缝隙自动成为隔挡，比分格线更像塑料模具，且零新增元素。
④ 视觉 米饭改为「盒底露出」 取消白卡与外描边，只留顶部一道实线隔挡；左右用负 margin 贴到盒壁 ⇒ 视觉上它就是盒底，而不是第五个格子。这才对得上"饭在底座"这个说法。
⑤ 结构 份数并入饭位；下方改「应付」 饭位承载「吃什么 + 几份」，下方只答「付多少」——分工比原来清楚 （原来饭位挂单价、下面又说合计，两个 25.80 并排容易绕）。 同时把「单笔最多 10 份」并入同一行，少一个块。

二、优化后，主按钮能进首屏吗

口径：375px 视口（750rpx ⇒ 1rpx=0.5px），间距/字号取 tokens.scss v2.1 实际值。均为推算，非真机实测。

【优化后 · 普通用户视角】（大多数用户不是团长 ⇒ 无团长横幅、无跟随团长卡）
  倒计时         ≈  96px
  天盖 + 盖缝    ≈ 103px
  地盒           =  11 + (186×2 + 8) + 48 + 11 = 450px
    其中单格     =   6 + 129(图位) + 6 + 22(菜名) + 17(来源) + 6 = 186px
  应付卡         ≈  72px（原「合计卡 + 独立提示行」= 134px ⇒ 省 62px）
  主按钮         ≈  64px
  ─────────────────────────────────
  到按钮底部     ≈ 785px

  iPhone SE   (667px 视口) → 需下滑约 1 指
  iPhone X/11 (812px 视口) → ✅ 主按钮首屏可见

【团长视角】再 + 团长横幅 70px + 跟随团长卡 110px ≈ 975px → 需下滑

⇒ 结论：普通用户（占绝大多数）在主流机型上不用滚就能看到"立即预订"。
   这是优化前做不到的。优化前同口径 = 96 + 98(天盖) + 484(盒) + 134(合计卡)
   + 18(独立的「单笔最多」行) + 64(按钮) = 894px ⇒ 本轮省 109px。
⚠️ 口径声明：以上为按 token 推算，落码后必须真机核对一次。 另：团长视角要不要把那两块挪走（比如折进「我的」或做成可收起的条）， 是个独立议题，我没动——它涉及团长的工作动线，得你定。

三、落码时仍然要守的（沿用 v0.2，一条没减）

  1. 时刻一律从响应取，端上不写死。cutoffAt / deliverAt；取不到就整行不显示，不回落写死值（回落值就是新的硬编码）。
  2. 格子顺序 = 服务端顺序，端上不重排。dishesOfSetMeal 已按 slot ASC 下发；端上一排序就造出第二份编排口径。
  3. ⛔ 不许写 <ab-icon> 组件。唯一写法 <text class="abi abi-16">{{ I.chart }}</text>，script 段不许出现 I.xxx。
  4. ⛔ 「来自：X ›」不许变成第三方平台的东西。名称 / 标识 / 链接 / 可跳转物 / 可复制口令，五项全禁（撞 5.10 / 5.20 / 5.15.4，处理是下架）。它现在指向自家溯源页，是安全的。
  5. 菜数 ≠ 4 时要有降级。dishesOfSetMeal 目前没有过滤主食槽 slot=5，只是种子恰好没编主食。规则：4 条走 2×2；3 条走 2+1 左对齐；≥5 或 <3 退回纵向列表。
  6. 图位优先读 d.imageUrl，读不到再回落到 iconfont 占位图标。注意这里是允许回落的——因为它回退的是"没有图"，不是"假装有图"，与时刻那条纪律不冲突。

四、优化后与实物的对应关系

  • 盖沿 + 盖缝 = 天盖压住地盒。实物开盖时最先看到的就是那道边。
  • 盒身沉一档 = 塑料隔挡。实物里四格之间是凸起的隔挡；屏幕上靠"盒底深、格面白"这个明度差表达，不画格线。
  • 米饭贴盒壁 = 底座。实物里饭格最长、贴着盒壁；屏幕上用负 margin 顶到盒身边缘，视觉上就是盒底。
  • 盒色不搬。实物的青绿是耗材色，屏幕仍走品牌米色 + 暖棕。
  • 图位仍是硬前置。四张 1:1 俯拍图——没有图，③ 那处隔挡效果出不来（白格子空着，看不出"格子"）。

五、还剩三件要你拍板

  1. 图位比例 1:1 还是 4:3？1:1 最像实物（本稿按 1:1 画）；4:3 能再省约 40px。 我仍倾向 1:1——① ③ ④ 三处优化全部依赖"格子看着像格子"，图一压扁就散了。
  2. 团长那两块（横幅 + 跟随卡）要不要挪走？它们让团长视角多出 180px， 把大多数用户能受益的首屏改善，让少数团长承担了下滑。 可选：折进「我的」/ 做成默认收起的条。涉及团长工作动线，我没动。
  3. 要不要在图位上加档位角标（主荤 / 半荤 / 素菜）？ 数据真实存在（d.slot + SET_MEAL_SLOT_LABEL），但会占图位。 我的建议是不加——四格已经够满，且角标会挡住实拍图这个主角。
