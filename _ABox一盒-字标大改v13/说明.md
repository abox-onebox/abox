# 一盒 · 字标大改（v13）

> 针对 v12 的 `03_字标_一盒`（只是把「一盒」两个楷体字平铺 + 一点投影）做的大幅重做。
> 交付：3 套字标方向 + 1 张应用板，均为 1024 画布（应用板 1200×1000）。

## 一、先说我认下的问题

v12 的 03 不是"设计"，是"打字"：
- 两个楷体字默认并排，**没有任何刻意的关系**；
- 楷体字的 **em 框上下留白极大**，导致「一」和「盒」之间空出一块，读起来是两根独立的杆；
- 汉字的**字身留白**没处理，横排时「一」（左右留白最大）和「盒」看着像断了；
- 只有一层 `text-shadow` 假装压印，没有容器、没有比例、没有主张。

所以这次动的是**结构**，不是调色。

## 二、三套方向

| 文件 | 名称 | 做法 | 适合 |
|---|---|---|---|
| `01_方印_竖排.png` | **方印 · 竖排** | 双线方印框；「一」作盖沿压在上面，「盒」作盒身在下；竖读即「一盒」 | 主标识 / 头像 / 信物 |
| `02_横匾.png` | **横匾** | 棕底圆角横印（像老字号招牌），米色「一盒」横排，内嵌细线框 | 包装腰封 / 门头 / 横幅 |
| `03_素横排.png` | **素横排** | 米纸无框；「一」缩到盒的七成、对齐盒的视觉重心；细规 + ABOX | 名片 / 文档抬头 / 网页导航 |
| `04_应用板.png` | 应用板 | 方印字标 + 名片 + 腰封 + 小程序图标，一页看落地 | 判断"能不能用" |

## 三、这一轮真正的技术关键（不是审美，是几何）

1. **压掉楷体的行框留白**：`一` 的 em 框里上下各有约 0.4em 空白，直接排版必然"断开"。用**负 margin**（竖排 `margin-top:-128px`）把「盒」提上来，才读成"盖在盒上"。
2. **字身留白做负字距**：横排「一」左右留白各约 0.1em，必须用 `margin-left:-6px` 才贴得自然；收过头（-38px）会直接钻进「盒」里——已实测。
3. **对齐视觉重心而非几何中心**：「盒」下部的「皿」重，几何居中会让「一」显高，故「一」下移 20px。
4. **楷体不要描边加粗**：试着用 `-webkit-text-stroke` 加粗，收笔会被糊成圆头，失了楷体的锋；镂空描边更糟（笔画粗细悬殊，内部只剩细缝，像双线）。因此**回归天然楷体、靠字号取分量**。

## 四、诚实的话

这三款是**"安静的传统高级"**——像一枚真印、一块真招牌。
优点：40px 仍立得住、气质稳、跟你的米/棕 + 楷体完全一致。
短板：**不"炸眼"**。如果你要的是更当代、更冲的（比如把字做成图形、双色叠印、或字形重构），那是另一条路，我现在这三款都不是。
