# ABox 一盒 · 小程序图标 十款设计记号（v4）

> 应要求「十个十个的来」：一次放出十个方向，覆盖十种设计语法。全部是**记号**，不是插画；每个都自带意义、能 40px 立住。

## 十款一览

| # | 名称 | 语法 | 一句话含义 |
|---|---|---|---|
| 01 | 楷笔一 | 书法 | 米纸落一笔楷体「一」；一盒 / 周一 |
| 02 | 折角封盒 | 折角（负空间） | 封 / 合 / 一周一封 |
| 03 | 双盒相拼 | 交叠 | 同事顺手拼一盒，重叠生团 |
| 04 | 方印A | 双框印章 | A 焊进「一盒」方印传统 |
| 05 | 合 | 字标几何化 | 合团 / 合盒 / 合得来 |
| 06 | 热乎一笔 | 气韵笔触 | 那口 11:30 还热乎的气 |
| 07 | 一饭四菜 | 点阵 | 一大点 + 四小点，点到即止 |
| 08 | 周一环 | 环 + 节点 | 一圈是周，一点是周一 |
| 09 | 升 | 托举笔 | 把饭送到工位的那股劲 |
| 10 | 套盒 | 同心套叠 | 一盒里还有一盒，容器与深度 |

## 怎么选

- **想最抓眼、最贴楷体品牌** → 01 楷笔一 / 06 热乎一笔（都是"一笔"路线，书法感强）。
- **想要信物感、像品牌徽章** → 04 方印A / 02 折角封盒。
- **想突出"团 / 拼 / 合"的社交属性** → 03 双盒相拼 / 05 合 / 08 周一环。
- **想要安静、耐看、极简** → 10 套盒 / 07 一饭四菜 / 08 周一环。

## 规格

- 画布 1024×1024，PNG 可直接上传微信小程序头像。
- 纯双色：米纸 `#F6F0E5` × 暖棕墨 `#6E5435`；投影为暖棕 28–30% 透明，不出第三色。
- 图形收在内切圆 r=340 安全区，圆形/圆角遮罩都不缺角。
