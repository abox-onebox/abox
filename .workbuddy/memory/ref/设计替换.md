### 七·补、端上三档锁的**唯一可行写法**（S7.5 收口 · 2026-09-21）

> ⚠️ S7.5 的核心结论，**动端上图标前必读**。

- ⛔ **`<text>` 不能内嵌自定义组件** —— 微信官方 text 组件 tip 原文：「text 组件内只支持 text 嵌套」。
  端上图标位绝大多数是「图标 + 中文」同在一个 `<text>` 内（卡片标题 / 菜单行 / 提示条 / 按钮文案），
  这些位置写 `<ab-icon>`，组件节点会被渲染层**静默丢弃**（不报错、不警告、位置空着）。
  ⇒ 这才是端上 `components/ab-icon/` **长期 0 引用**的真因（不是「忘了用」）。
- ✅ **唯一写法 = 统一 class 约定 + 嵌套 `<text>`**：

  ```html
  <text class="abi abi-16">{{ I.chart }}</text>      功能档（行内 / 按钮 / 独立）
  <text class="abi abi-deco-40">{{ I.rice }}</text>  装饰档
  ```

  嵌套层上的 `font-size` 是**直接声明**，能盖住父级继承来的文字字号 —— 这是三档锁在**混排语境**下成立的前提。
- ⭐ **通用结论（跨项目可复用）**：**设计规范没有「统一承载点」⇒ 结构上不可机械校验 ⇒ 必然回潮。**
  对策不是「更努力地遵守」，而是**把渲染点收敛到一个 class 约定**，让规范变成**可门禁**的东西。
  本项目落地 = 新增常驻门禁 `icons:lock`（7 断言 + 9 自证）。
  **后台不受此限**（Vue 组件渲染，不吃微信 `<text>` 限制）⇒ `AbIcon` 保留。
- ⚠️ **同源教训**（S7 登记的 78 处 → 0 处命中）见 `§十一 · S7.5`。

## 十、统计判据陷阱（已多次踩）

1. **emoji 必须先剥注释再数**（注释里的符号是文档说明）
2. 正则**须含 `U+2600–27BF` 区段**
3. 统计前须**剥 `<code>` / `<pre>` 里的转义样例**（`&lt;div class="hint"&gt;` 会被当真实元素）
4. 组件目录可能是 `xxx/index.vue` ⇒ `glob("*.vue")` 会**扫出空集**
5. ⚠️ **禁止手写数字入文档**（菜单入口曾手写 36，实为 **39**）—— **一律脚本产出**
6. ⚠️ **扫描报告会过期**：`_tmp/dsg/scan-report.json` 是**某个时点的快照**，
   用户随时会新加页面/新加 ⚠️ 说明 ⇒ **用之前先重算**（见 §十二 重算流程）。
   实测该报告三处过期：后台 emoji 14/5→**22/8** · 菜单 31/5 组→**39/8 组** · 组件 `table` 引用数
7. ⚠️ **码位区间别手写 `\UXXXXXXXX`**：`"\U000002600"` 写多一位 ⇒ Python 只取前 8 位（U+0260），
   区间变成 U+0260–U+27BF ⇒ **把大半个 BMP 吞成 emoji，误报 82 万处**。
   ⇒ 一律用 `chr(a)+"-"+chr(b)` 拼装，并带「必报/必不报」样本自证
8. ⭐⭐ **判据必须按其「作用域」写** —— 跨了作用域就**恒红**，而**恒红与恒绿同罪**（都等于没有检查）。
   实测：`verify-regen.py` 断言执行清单 `emoji == 0`，实测 **27 处**（全是 `⚠️`/`✅`）。
   而本工作区 **28 份 `_ABox*` 文档全部**在用 `✅/⚠️`（里程碑计划 **87/167**、接口规范 **17/117**、
   冻结清单 **4/113**）⇒ 约定显然是「**文档可用标注符号**」；P0 红线管的是「**UI 功能图标**」。
   ⇒ 修法：**重划作用域、不削弱**（放行 `⚠ ✅ ❌` + VS16，象形 emoji 仍须 0，并补「象形必报 / 标注不报」自证）。
   ⇒ **裁决顺序**：先查「项目自己的既有约定」（机械 grep 全量同类文件），**再**决定改判据还是改内容 ——
   不要凭偏好，也不要为了让门禁转绿就直接放宽。
   ⚠️ 这条能躺 3 轮无人发现，**是因为该脚本不在 `gate.mjs` 内** —— 手工脚本 = 没人跑 = 事实上的恒绿/恒红。
   同一原因下本项目已连续两次中招（前一次：`ui-gate.py` 的「时间线节点 15px」无定位子串恒红）。
