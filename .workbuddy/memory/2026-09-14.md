## v4.8.2 —— 手机端后台侧边栏修复（本日最后一次）
**用户反馈**：手机端看不到后台侧边栏；即使展开抽屉也是一片空白。
**两个真根因**：
1. **抽屉一片空白** —— `@media (max-width:900px){ .admin-sidebar{display:none} }` 把**抽屉内部**复用的 `.admin-sidebar` 也一起隐藏了，抽屉只剩背景。
   修复：改为 `.admin-body > .admin-sidebar { display:none }`（只隐藏内容区常驻侧栏），并新增 `.admin-drawer .admin-sidebar{width:100%;border-right:none}`。
2. **看不到/定位错** —— `.admin-shell` 缺 `position:relative`；抽屉原为 `position:absolute` 易被 `overflow:hidden`+圆角裁切；初始展开依赖 `matchMedia` 不可靠。
   修复：`.admin-shell` 加 `position:relative`；≤900px 时抽屉/遮罩改 `position:fixed` + 高 z-index，`overflow:visible` 放行；改用 `window.innerWidth<=900` 判断。
**交互增强**：窄屏进入后台**默认展开抽屉**（`_adminDrawerClosed` 标志记住用户关闭动作，切页不再自动弹出；进入后台角色时重置为展开）；汉堡按钮加"菜单"文字。
**测试增强**：`tests/render_check.js` 增加"移动端抽屉专项"（模拟 390px 视窗，7 项断言 + 关闭态断言）全过。
**校验**：括号配对 ✅ / nav-stack 61 ✅ / 渲染 11 ✅ / 移动抽屉 7 ✅
**部署**：已同步 https://abox-prototype.app.workbuddy.host/ （verified）

### 经验（重要）
- **`html`/`bodyHtml` 变量改名后必须全局搜残留**：`grep -n "^\s*html +="` 能一秒发现。已由 render_check.js 自动兜底。
- **移动端隐藏侧栏时，注意抽屉内部复用的是同一个 class** —— 用子选择器限定作用域（`.admin-body > .admin-sidebar`），不要裸写 `.admin-sidebar{display:none}`。
- **fixed 元素需要祖先无 transform**：`.page` 有 `fadeIn` 动画（transform），动画期间会临时成为 fixed 的包含块；动画结束即恢复，无实际影响。

## v4.8.3 —— 手机端后台导航改横向标签条（本轮终版）
**用户反馈**：抽屉能看见了，但"收不回去""占的版面太大，不利于看其它内容"。

### 根因（重要教训）
**11 个后台页面各自渲染了一份抽屉，`id="adminDrawer"` / `id="adminDrawerMask"` 在整份文档里重复了 11 次**。`document.getElementById` 只返回**文档顺序第一个**（即 P27 里的那份）。用户切到 P30 等页面后，点 ✕/遮罩改的是 P27 那份隐藏 DOM，当前页的抽屉纹丝不动 → "收不回去"。
**通用教训**：SPA 里 `renderAll()` 预渲染所有页 = 同一个 id 会出现 N 份。**任何 getElementById 都必须改成「先取 `.page.active`，再 querySelector」**。

### 方案更换（放弃浮层抽屉）
手机端（≤900px）不再用浮层抽屉，改为 **TopBar 下方一条横向可滑动的标签导航条** `.admin-mobile-nav`：
- 常驻可见（不再有"看不到/找不到"）
- 只占约 48px 高，内容区全宽（解决"占版面"）
- 没有开合动作，从根本上消灭"收不回去"
- 11 个条目按 4 组用竖线 `.admin-mobile-nav-sep` 分隔；当前项金底高亮；切页时 `scrollAdminNavIntoView()` 自动把高亮项滚到中间
- 面包屑已经显示分组（运营后台 / 业务 / 团长管理），所以标签条不必再写组名

### 代码改动
- CSS：删除 `.admin-hamburger / .admin-drawer / .admin-drawer-mask / .admin-drawer-header / .admin-drawer-close` 整套；新增 `.admin-mobile-nav*`（~50 行）
- JS：
  - 删除 `toggleAdminDrawer` / `_closeAdminDrawer` / `_isNarrowScreen` / `_adminDrawerClosed`（注意：`switchTab`/`switchRoleFn` 里对 `_adminDrawerClosed` 的引用必须一并删除，否则运行时报 ReferenceError）
  - `_adminSidebar(activeIdArr)` 去掉 drawer 参数；新增 `_adminMobileNav(activeIdArr)`、`scrollAdminNavIntoView()`
  - `adminShell()` 里 TopBar 去掉汉堡；主体前插入 `${_adminMobileNav(activeIdArr)}`
  - **`scrollAdminNavIntoView()` 必须锚定 `.page.active`**（同 id 重复问题）
  - 导航项加 `data-nav="Pxx"` 便于测试与调试
  - **顺带修复 `refreshCurrentPage()`**：原来 `sec.innerHTML = render()` 把 `.phone-shell/.desktop-shell` 外壳一起冲掉，现改为优先替换壳内 HTML（P6 筛选切换不再丢手机壳）

### 测试
`tests/render_check.js` 移动端段重写为"横向导航条专项"：**9/9 通过** + 全量"11 页均含导航条并高亮自身 11/11"。另：括号校验 ✅、nav-stack 61 ✅。
**部署**：https://abox-prototype.app.workbuddy.host/ （verified）

### 复用清单（下次改后台导航先看这条）
1. 任何 `getElementById` → 改 `.page.active` 作用域查询
2. 手机端不要用浮层遮挡内容，优先横向标签条 / 图标轨道
3. 改 JS 删函数时，全局 grep 调用点（尤其 `switchTab`/`switchRoleFn`/`afterSwitch`）

### 修掉的 6 个真缺陷（**均为实测暴露，静态检查查不出**）
1. **金额跨库读取不一致** — MySQL 返回 `string`、SQLite（NUMERIC 亲和）返回 `number`，`'25.80'` 比对会失效
   → 新增 `moneyTransformer(2)` / `rateTransformer(4)` / `coordTransformer(6)`，**批量注入 37 处 decimal 列**
2. **自增主键跨库不兼容** — SQLite 规定 `AUTOINCREMENT` 只能挂 `INTEGER PRIMARY KEY`；`@PrimaryGeneratedColumn({type:'bigint'})` 直接报 `SQLITE_ERROR`
   → 新增工厂 **`PkColumn()`**（sqlite→`integer` / mysql→`bigint`+transformer），**替换 24 处**
3. **4 处「复合唯一索引」被误写成单列**（与已评审 DDL 不符，其中 `ab_commission` 直接**和 C9 退款反向冲销冲突** —— 同订单 normal+reversal 会被唯一键拦住）
   → 改为类级复合索引：`ab_commission(order_id,type)` / `ab_meal_assignment(meal_date,building_group_id)` / `ab_delivery_record(meal_date,building_group_id)` / `ab_supplier_dish_daily(supplier_id,dish_id,produce_date)`
4. **共享包跨包源码编译触发 TS6059** — api-server 是 tsc/CJS，`paths` 指到 packages 源码会把跨包源码拉进编译单元
   → 两个包改为**预构建 `dist`（js+d.ts，CJS）**，api-server 去掉 `@abox/*` 的 paths 走包解析；`exports` 用 `types/import/require` 三分支（Vite 侧仍吃源码，行为不变）
   → ⚠️ **连带发现隐蔽副作用**：文件落在 rootDir 之外时 tsc 会用 `../../` 回溯算输出路径，把 `.js` **静默写进 `packages/*/src/`**。已清干净并做对照实验确认不再复现
5. **tsconfig `rootDir`/`outDir` 写在 `extends` 基座里** → 被解析到 `packages/tsconfig/`（TS6059 覆盖全部 app 源码）→ 移到各 app 自身声明
6. **种子清空顺序违反 FK** → 板块各自 `clear()` 是「父→子」顺序，清父表时子表仍有引用
   → 改为 `wipeAll()`：关外键 → 全表 DELETE → 开外键（与声明顺序无关）
