- 触发：用户「老规矩，有修改就全面测一遍，细致、不漏测不假测」。跑 `gate full`（31 静态 + seed/e2e:m1/m2/m3 4 道真发请求）→ **通过 35/35 · 全绿**（e2e:m1 116/116、m2 162/162、m3 1351/1351、jest 62/62、三端 build 全过）。

  - 修法：数组**移回 `1700000000005`**（模块级 `export const`，位于 `up()` 前，被 parity 纳入）；`1700000000006` 直接 import 复用同一份（不复制第二份，避免 parity 解析出重复改名）；`migration-utils` 只留 6 个辅助函数（仍解决 `migration:run` 的 constructor 报错）。生产迁移仍幂等。
- **缺陷2（契约真失败·非假测）**：`e2e:m3` 1350/1351，快消品商品 `category:null`（设计如此，端上 `dishIcon` 回落包裹图标）但后台 `GET /admin/dishes` 出参 `categoryLabel = DISH_CATEGORY_LABEL[null] ?? null` → null，违反「每行带中文档位标签」契约。
  - 修法：`item-admin.service.ts` 两处 `categoryLabel` 加 `?? '通用'` 中性回落（update 响应 + list decorate）；`costPriceYuan` 始终字符串安全。**端上 `dishIcon` 读原始 `category` 字段，与此改动解耦，不受影响。**
