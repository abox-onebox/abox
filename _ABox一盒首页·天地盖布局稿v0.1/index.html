思路：首页的排版 = 产品实物的排版。用户在屏幕上看到的格子顺序，就是打开盒盖后看到的格子顺序—— 还没吃，先"开"了一次盖。菜占四格，饭占通栏，价格和预订按钮落在"饭"的位置： 饭是最后一口，也是下单这个动作的落点。 下面 A 是纯布局稿，B 在 A 的基础上把「来自：谁」做成原地展开（承接之前供应商页的合规义务）。

点任意菜格，来源厨房的证照信息在格子下方原地展开，菜单不消失、不打断下单。 这是之前供应商页讨论里"最好的合规页是没有页面"那个结论， 正好借着首页改版一起落掉——原独立供应商页可以降级或移除。

布局对照：实物 → 屏幕

  • 上排两格 = 荤素对角。实拍里左上是素菜、右上是荤菜，屏幕上保持对角摆放，视觉重心平衡。
  • 中排两格 = 主荤靠左。实拍的红烧肉在中排左侧，屏幕上把最硬的菜放同一位置，用户肌肉记忆一致。
  • 通栏 = 米饭。实物里饭盒最长、最靠底；屏幕上通栏放米饭 + 价格 + 按钮，底座 = 决策位。
  • 盒色不搬。实物的青绿是耗材色，屏幕上仍走品牌米色 + 暖棕，格子用白底描边代替塑料盒边。
  • 图位要求：四张菜照统一俯拍、1:1 裁切，与实物俯视角度一致，整屏看才像"俯视一盒"。

落地时要说的三句话

  1. 菜名与"来自：谁"全部取接口，页面不写死；取不到的菜整格不显示，不留占位兜底。
  2. 时刻不写死：「下一个工作日 / 11:30 到楼 / 截单」都从接口取（daily.cutoffAt / deliverAt），取不到就不显示。
  3. 图片是硬前置：这个布局成立的前提是四张 1:1 俯拍实拍图。没有图，格子只剩文字，"开盖感"就没了——建议按实拍同角度补拍。
附带一个待你拍板的事：如果 B 方向成立（首页原地展示证照），独立供应商页的入口就可以删， 之前供应商页的所有讨论就此收口——首页 + 原地弹层 = 更完整的答案。
