一 条 分 界 线

要「证明你是你」「花你的钱」「动你的账号」的 —— 只能你做。

能写成文件、能在命令行里跑完的 —— 我来做。

一、三类「只能你做」的动作

不是我不想代劳，是这三类在流程上就绑死了你的身份，任何代理都无法绕过。

类型典型动作为什么只能你
身份核验 腾讯云企业实名、法人扫脸、备案核验短信（12381）、小程序主体认证 要法人本人身份信息，验证码只发到你手机上
花钱 买服务器 / 域名 / 证书、微信支付商户号、对公打款验证 要你的支付凭证与对公账户
账号操控 腾讯云控制台点击、微信公众平台提审、类目申请 每次登录都要你手机扫码，账号不能代持
附带一条法律责任

备案与主体认证材料的真实性由法人负责。所以这些材料我可以替你起草、逐字段写好该怎么填，但最后一键提交必须你按，且提交前你要过一遍内容。

三、阶段 B · 服务器部署（以我为主 · 前提是给我 SSH）

本机实测结论（这是分工能往我这边挪的原因）

这台电脑已装 OpenSSH 10.3p1 + scp + git 2.55.0。
意思是：你把服务器 SSH 免密配好（一次，5 分钟），后面这些步骤我可以直接登上去跑，不需要你粘贴任何命令。
本机未装 Docker —— 不影响，镜像本来就在服务器上构建。

#动作谁做我的交付物 / 用哪个脚本
B1服务器初始化：装 Docker、固定时区 Asia/Shanghai、开防火墙我 · ssh初始化脚本（幂等，可重复跑）
B2把代码送到服务器（git clone 或 scp）我取决于仓库是否可拉取
B3生成 .env.prod我 + 你我生成模板与校验脚本；你只填真实密钥（密钥只有你有）
B4宿主机 nginx + certbot 免费 DV 证书我 · sshnginx 配置我写好（只能走这条路，见下方 R10）
B5构建镜像 + 起容器（首次部署）我scripts/deploy.sh（已有）
B6核对两支迁移都已应用我判据见下方「B7 陷阱」
B7健康探针 3/3我scripts/healthcheck.sh
B8备份一次 + 回滚演练一次我backup-db.sh / restore-db.sh / rollback.sh
B9注册定时任务（结算 · 备份 · 巡检）我install-cron.sh 先 --dry-run，再真注册
B7 陷阱 —— 这一步不能只看「那一步绿了」

项目的迁移配置只匹配 *.ts，而编译产物在 dist/ 下是 *.js —— 零命中。而 TypeORM 找不到迁移不报错、正常退出 0，部署流水线会显示 ✅，实际上所有建表语句从未执行。

唯一有效判据：migration:show 必须同时列出 Init1700000000000 和 ParityFix1700000000001，两支都是 [X]。少一支就等于没迁移。

为什么 HTTPS 只有「宿主机 nginx」一条路

项目有硬约束 R10：一期只允许一个 API 实例（时间线是进程级单例）。云负载均衡 CLB 会引入未验证的第二实例形态 —— 症状是「同一分钟下单，一台过、一台不过，两边都不报错」，极难排查。所以不买 CLB，证书装在宿主机 nginx 上。

五、要开工，我需要你给三样东西

只这三样。给了之后阶段 B 我可以全包，不用你再插手。

#我需要什么怎么给不给我会怎样
1服务器 SSH 访问权（公网 IP + root 或 sudo 用户的免密登录）你把公钥加到服务器退化成「我出清单、你粘贴命令」的半自助模式
2服务器公网 IP + 已解析的域名直接告诉我装不了证书、配不了 nginx
3.env.prod 里的真实密钥（数据库密码、JWT 密钥等）你自己填进我给的模板我可以生成随机强密钥，但要把它们抄进你的密码管理器，否则丢了要重来
关于第 3 条的两个安全口径

① 推荐你自己填：你不必把生产密钥贴进对话。
② 如果让我生成：我用 openssl rand 在服务器本地生成、直接写进 .env.prod（权限 600），密钥内容不经过对话，只在最后告诉你存放位置。这比手打更安全 —— 手打容易造出弱密码，也容易在聊天记录里留痕。

如果选 ① 或 ②，有一个绕不开的话题要提前说

把 SSH 交给我 = 我能在这台服务器上执行任意命令。这是真实的能力，也是真实的风险。三个可控点：
① 我可以只用你给的专用部署账号（不做 root 直登），权限够跑 docker 即可；
② 每一条要执行的命令我都先贴出来给你看，你认可再跑（等价于逐条确认，但不用你打字）；
③ 部署全过程中，凡涉及删数据、改表结构、覆盖文件的动作，一律先停下问你。
你可以随时收回：改一次密码即可立刻失效。
