# ABox 一盒 · 小程序图标 六款方向

> 画布 1024×1024 · 纯双色 米底 `#F6F0E5` × 暖棕 `#6E5435` · 全部图形落在内切圆 r=340 安全区（66% 占位）
> 输出：`方案总览.png`（六款对比）+ 6 张 1024 母版 PNG（可直接上传）+ 6 份 SVG 源（可无级放大用于包装/印刷）

---

## 一、六款速览

| # | 名称 | 一句话 | 强项 | 短板 |
|---|------|--------|------|------|
| 01 | **盖身分离** | 宽盖压窄身，肩上留台阶 | 零线条，纯剪影就是天地盖；缩到 40px 最稳 | 太"正"，少了点品牌个性 |
| 02 | **一线盒** | 方框里一道盖缝横线 | 最省墨、最极简；印刷成本最低 | 略像通用线框图标，需要靠配色拉开 |
| 03 | **A 字** | 只留首字母，粗笔画 | 40px 辨识度最高；做大了也好看 | 单独的 A 不够独占，容易被认成别的品牌 |
| 04 | **A 入盒** ⭐ | A 装进方框 = A Box | 双关直接、最像 App 图标、最有独占性 | 方框占位偏满，后续扩展空间略小 |
| 05 | **热气一盒** | 三条不等高热气从盒里升起 | 唯一带"热"的，能说现做 | 笔画多一道，40px 下最考验缩放 |
| 06 | **掀盖** | 盖被掀开一角 | 唯一有动作，食欲感最强 | 倾斜结构在极小尺寸会略微发糊 |

---

## 二、我的建议

**首选 04「A 入盒」**，理由三条：

1. **它自己会解释自己**。一个框、一个字母，看到就念得出 A Box——不用配文字，这对小程序头像特别重要（进列表时只有图标，没有名字跟着）。
2. **独占性最好**。01/02 是"一个盒子"，谁都能用；04 是"A 装进盒子"，只有你能用。
3. **缩放最抗压**。骨架只有 4 笔，40px 下依然方正清楚，不会像 05、06 那样糊边。

**备选 01「盖身分离」**：如果你更想让人第一眼认成"盒饭"而不是"品牌"，选它。它最像一只真实的天地盖，也最适合直接印在盒盖上做无字标——盖上一压，就是个印。

**不建议单用 03「A 字」**：字母标在陌生品牌上不占便宜，除非后面配强势的广告投放把它"喂"成资产。

## 三、规格（选完即可直接进开发）

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 1024 × 1024 | 微信要求 144×144 以上，出 1024 是为了各处缩放不糊 |
| 格式 | PNG（3 通道无透明）+ SVG | 小程序上传用 PNG；包装印刷用 SVG |
| 颜色 | `#F6F0E5` / `#6E5435` | 纯双色，无渐变、无阴影、无透明 |
| 主体占位 | ≈ 66%，内切圆 r=340 | 微信各入口遮罩不一致（圆角方形为主、部分场景圆形），按圆安全区设计两边都不缺角 |
| 最细笔画 | 34px | 40px 显示下 ≈1.3px，仍不断线 |
| 圆角 | 图形自身 8–10px | 只做"去锐"处理，不抢方形骨架 |

## 四、确定后还要补的（我可以直接做）

1. **反白版**：米底棕字 ↔ 棕底米字，两套都要有（盒盖是米色、海报可能是深色）。
2. **纯单色版**：全黑 / 全白各一份，给盖章、烫金、单色印刷用。
3. **圆角遮罩测试图**：把选定款贴进微信列表、发现页、分享卡片的真实尺寸里看一遍。
4. **与字标配对**：和 v4 八套字标各配一次，定"图标 + 字标"的横排/竖排组合规范。
5. **尺寸阶梯导出**：1024 / 512 / 216 / 144 / 108 / 72 六档。
