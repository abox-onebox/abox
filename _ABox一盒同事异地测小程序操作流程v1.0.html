同事异地测试小程序 · 操作流程

ABox 一盒 · v1.0 · 2026-10-03 · 祝总专用

一句话结论：前天你扫的那种「预览码」只有管理员/开发者本人能扫，同事扫会报错。要让同事异地测小程序，必须改走 体验版 —— 把同事加为「体验成员」，并让他在手机上打开调试，这样才允许访问 http://IP:8081。

微信的规则：正式版必须 HTTPS + 备案域名；只有「调试态」才豁免域名校验并允许 IP 与 http。我们没有域名证书，所以实测阶段只能靠调试态。

一、三种扫码入口的区别

入口谁能扫有效期能测
预览码（开发版）仅管理员/开发者本人约 30 分钟不行
体验版（推荐）后台添加的体验成员较长（约 7 天）可以
正式版所有人长期需 HTTPS + 备案（暂无）

三、你要做的（4 步，约 10 分钟）

1
你做腾讯云控制台放行 8081 进入云服务器控制台 → 防火墙/安全组 → 添加入站规则：TCP : 8081，来源 0.0.0.0/0。
这是目前唯一卡住的一步（我已实测公网 8081 仍不通，返回 000；8080 后台已通）。放行后告诉我一声，我立刻复验。
2
你做把同事加为「体验成员」 登录 mp.weixin.qq.com → 左侧「管理」→「成员管理」→ 体验成员 → 添加同事微信号。
没加的话，同事扫码会提示「暂无体验权限」。
3
你做微信开发者工具上传代码 打开微信开发者工具 → 导入项目 → 目录选上面的产物目录，AppID 填 wx389db239bcec75ca → 点右上角「上传」→ 填版本号与备注 → 上传成功。
然后到 mp 后台「管理」→「版本管理」→ 在开发版本那一行点「设为体验版」。
4
你做把体验版二维码发给同事 版本管理 → 体验版本 → 点击「体验二维码」→ 保存图片发给同事。
如果只测一个账号，到此就够用。若要多人同时各测各的，见下面第五节。

四、同事要做的（3 步）

1
同事做微信扫码打开小程序 打不开 = 还不是体验成员，回到第 2 步。
2
关键同事做打开调试（这一步不能省） 点小程序右上角「…」→ 找到「打开调试 / 开发调试」→ 开启 → 退出小程序后重新打开 → 屏幕右下出现绿色 vConsole 按钮即成功。
为什么必须：不开调试，微信会强校验合法域名，我们的 IP + http 会被直接拦掉，表现为「网络异常 / 页面空白 / 本楼今日未开团」，很容易误判成功能坏了。
3
同事做开始测试 正常走下单流程。支付走的是模拟支付（自动成功），不会真扣钱。

五、多人同时测怎么办（身份隔离）

注意：所有人在同一台手机上默认都是同一个账号（默认身份 dev:1001）。两人同时测会互相看到对方的订单和余额。

解决办法：给每个人生成一个带参数的小程序码，参数格式 devCode=tom、devCode=lucy（字母数字，最长 32 位）。谁的码谁扫，就是各自独立的账号。
这件事我可以代劳：用 AppSecret 调用微信接口直接生成几张带不同 devCode 的小程序码给你。需要时说一声。

六、三条红线（务必记住）

  • 上线前必须重新用正式模式构建上传。现在这版是「开发模式」，带 demoMode 后门，任何人指定 devCode 就能换成任意身份 —— 绝对不能出现在正式版。
  • 支付是假的。服务器当前 PROVIDER_MODE=mock，支付自动置成功。同事看到「支付成功」不等于真支付链路通。
  • 测试结束请告诉我下线。8081 是对公网开放的临时测试入口，用完应在安全组关掉。

七、想更快？还有一条路（H5，不用上传）

放行 8081 之后，直接把下面链接发给同事，微信里点开就是网页版：

http://154.8.164.180:8081/?devCode=tom

优点：不用上传代码、不用加体验成员、不用开调试，5 分钟开测，换 devCode 就是换人。
缺点：是网页不是小程序形态（没有胶囊 menu、导航栏观感不同）。建议先用它把业务跑通，小程序形态作为第二步验证。
